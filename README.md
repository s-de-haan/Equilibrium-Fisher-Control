# Getting started

This project uses ```python=3.11.9```, as well as ```torch=2.6.0``` and ```torchvision=0.21.0```. Please follow the instructions below to install the required dependencies and the dataset(s) to get started.

## Installation

First, you need to setup a virtual environment. To create a virtual environment, run the following command: 

```
python -m venv venv # create a python virtual environment called 'venv'
```

Once you've created your virtual environment, you need to activate it. To do so, run one of the following commands below:

```
# If you're using bash terminal
source venv/bin/activate

# If you're using C-shell (csh) terminal
source venv/bin/activate.csh
```

Now that you've activated your virtual environment, you need to install the required libraries in it. To do so, run the following command in your terminal:

```
pip install -r requirements.txt 
```

For more information on how to use virtual environment in Python, you may find [this tutorial](https://realpython.com/python-virtual-environments-a-primer/) helpful.
